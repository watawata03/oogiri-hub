# Oogiri Hub

Python (Django) の復習とポートフォリオ制作の一環として開発した、オンライン大喜利ミニSNSアプリです。
ユーザー同士でお題を出し合い、ユニークなボケ（回答）を投稿して「おもろい！」を競い合って楽しむことができます。

---

## 主な機能

- **ユーザー認証・管理**: Django標準の認証機能を活用したセキュアなログイン・アカウント管理。
- **お題の投稿・一覧表示**: ユーザーが自由にお題を投稿でき、一覧画面で閲覧可能。
- **ボケ（回答）投稿機能**: 各お題に対して、思い思いのボケを投稿して盛り上がれる。
- **「おもろい！」投票システム（トグル式）**:
  - ボケに対して投票が可能。
  - データベースレベル（`UniqueConstraint`）で「同一ユーザーの重複投票」を厳格にブロックしつつ、もう一度押すと取り消せる（トグル）親切設計。
- **日本時間（JST）対応**: 投稿時間が自然な日本時間で正しく記録・表示されるよう調整済み。

---

## 使用技術

- **言語**: Python 3.x
- **フレームワーク**: Django
- **データベース**: SQLite
- **フロントエンド**: HTML / CSS
- **バージョン管理**: Git / GitHub

---

## 画面イメージ・使い方

1. サイトにアクセスし、ログインして一覧から気になるお題を選ぶ。
2. お題に対する「ボケ」を投稿する。
3. 他の人のボケを見て「🔥 おもろい！」ボタンで投票する！
